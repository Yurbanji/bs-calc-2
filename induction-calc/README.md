# BS Calc

Локальное веб-приложение для сравнения конфигураций индукционной установки. Без зависимостей и сборки. Запуск: `npm start` или `node server.mjs`. Открыть http://127.0.0.1:4173. Проверка расчётов: `node --test tests.mjs`.

## Реализовано

- Неподвижный прут Ст3: диаметр, зона, температуры и время.
- Геометрия медной спирали и частота 7–60 кГц.
- 1–8 инверторов, катушки 30 витков, вторичка столба 1 виток.
- Столбы 1/2/4/6/8 и три разрешённые комбинации перемычек.
- Настраиваемые первичные последовательные/параллельные ветви при равномерном распределении катушек по столбам.
- Кассеты 2,24 / 4,48 / 11,55 мкФ; последовательное/параллельное соединение групп.
- Стандартные кассеты: один ряд содержит два последовательных участка по обеим сторонам столба. Для 0,056 мкФ по 3 параллельные кассеты в участке, всего 6 на столб; для 0,33 мкФ по 1, всего 2. Два ряда дают четыре последовательных участка, количество кассет удваивается, ёмкость группы уменьшается вдвое. «Настроить»: сборки из 1/2/3 последовательных конденсаторов 0,056 или 0,33 мкФ, число параллельных сборок в кассете и число параллельных кассет в участке задаются вручную. Ёмкость кассеты равна Cконденсатора × число параллельных сборок / число конденсаторов последовательно.
- Требуемые I/U индуктора, пределы источника, баланс нагрева, резонанс, схема, сохранение в браузере и экспорт JSON.
- Схема распайки первичных катушек: вертикальные столбы, цветные линии L1, L2 и далее, нумерация сверху вниз по инверторам и уровням. Каждая последовательная ветвь имеет свой L-номер; все её катушки и провода одного цвета. Первичная раскладка формируется регулярно по образцу PDF, произвольная ручная распайка и фазировка пока не задаются. Вторичная цепь доступна на отдельной вкладке.
- Чистые JPEG исходных схем находятся в `../output/schemes/`. Удалены только чисто красные векторные отметки; остальные элементы исходника сохранены.

## Границы модели

Электрические параметры индуктора — грубая поверхностная оценка, не проверенная на реальной установке. Материальные значения — редактируемые сценарные допущения, не полноценный справочник Ст3. Нет автоматического подбора геометрии, температурной зависимости магнитной проницаемости, гистерезиса, насыщения, распределения температуры, расчёта сердечников/охлаждения и проверки номиналов кассет. Постоянная теплоёмкость не учитывает фазовые превращения.

Все инверторы и ветви считаются синхронными, одинаковыми и равномерно нагруженными. Фазировка конкретных катушек не проверяется. Входные напряжение и ток одного инвертора задаются в интерфейсе; по умолчанию 540 В / 80 А, действующие значения. Каждый инвертор питает свою группу отдельных 30-витковых катушек на собственных сердечниках. Их вторичные напряжения складываются вдоль общего столба. Последовательные группы первичных катушек должны быть распределены симметрично; ввод проверяет только делимость общего количества.

Исправленная трансформаторная модель: UБС = Uинв·n·q·S/(30·a), IБС = Iинв·30·a/(q·S). n — инверторов, q — катушек на столб от каждого инвертора, a — катушек последовательно в первичной линии, S — столбов последовательно во вторичной ветви. Ток БС пересчитан из заданного входного тока; при вводе 80 А это идеальный доступный предел. Потери не учитываются, постоянный поправочный коэффициент для совпадения с измерениями не вводится. При двух инверторах, шести столбах, q=2 и a=3: 24 В / 3600 А либо 48 В / 1800 А при 540 В / 80 А на инвертор. При одном столбе, одном инверторе, q=6 и a=3: 36 В / 600 А при входных 540 В / 40 А.

У каждого столба своя одинаковая группа кассет. Каждая вторичная ветвь содержит S столбов и S групп последовательно. Cгр = Cкас·p/k; Cветви = Cгр/S; Cэкв = M·Cгр/S². Всего кассет M·p·k, количество не меняется при переключении перемычек.

Формулы и ссылки доступны в интерфейсе «Как получены результаты». Предел трансформаторной части выражен в кВА, а не в кВт полезного нагрева.
